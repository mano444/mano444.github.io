# mano444.github.io

**Hey Mano** — SoCal · Travel · Nature · Food · Tech — https://mano444.github.io/

Single static `index.html`, no build step, no cookies.

**To update:** edit the `EDIT ME` block near the bottom of `index.html`:
- `PHOTOS[]` — nature & travel gallery (images hosted on manowritingsblog.wordpress.com uploads)
- `FOOD[]` — food cards (dish, place, year, taste score, note)
- `TRAVEL_REELS[]` / `REELS[]` — reel cards (`url: ""` falls back to the Instagram reels tab)
- `BOTS[].template` — paste a URL to turn "Template coming soon" into a live link
- `YOUTUBE_URL`, `X_HANDLE`

**Stats:** https://mano444.github.io/stats.html — page views, unique visitors and link clicks
(free, no-signup [Abacus](https://abacus.jasoncameron.dev) counter, namespace `mano444-github-io`).
